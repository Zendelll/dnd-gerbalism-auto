# Автоматизация Гербализма и Алхимии для DnD 5e
Небольшое приложение, написанное для упрощения хоумбрю Гербализма и Алхимии.

*Приложение было создано без использования ИИ.*

**FUCK GENERATIVE AI**

## Текущие фичи
- Ролл по таблицам местности для поиска растений
- Автоматизация алхимии для удобного выбора ингредиентов и просмотра их эффектов
- Библиотека травника для просмотра всех существующих растений
- Создание случайного описания зелья для тех случаев, когда игроки просят узнать, какое зелье на вкус или какой у него запах.

## Запуск
Для запуска приложения достаточно установить зависимости и ввести команду:
```
streamlit run <путь_до_Herbalism.py>
```

Либо можно просто пользовать по ссылке https://herbalism-dnd-auto.streamlit.app/
